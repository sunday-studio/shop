Troubleshooting

Quick checks for the usual problems.

Checks

  1. 01
    Is the server healthy? The health check reports the database, OCR, the job queue, storage and backups. A line that fails tells you where to look.
    curl localhost:8080/healthz
make logs
  2. 02
    The app can't connect. The phone and the server must be on the same network, or on the same Tailscale network. Check the address and the port. If you said no to the local network question, allow it in the iPhone's settings for Shop.
  3. 03
    Wrong or lost password. Make a new one on the server.
    docker compose -f deploy/docker-compose.yml exec api shop password generate
    Five wrong passwords from one address lock it out for 15 minutes.
  4. 04
    A receipt stays on processing. The OCR engine may be down or busy. Check ocr and jobs in the health check. The first receipt after a start takes longer.
  5. 05
    A receipt says Needs review. The lines don't add up to the printed total. Fix them on the receipt, or confirm anyway. See Review and fix a receipt.
  6. 06
    A photo won't import. Use JPEG, PNG, HEIC or PDF. If the app can't find the edges, retake the photo flat and in good light.
  7. 07
    NAS backup is out of date. The backup folder wasn't available. Mount the disk or share again, then run a backup. See Update, back up and restore.
    make backup
  8. 08
    Old receipts look wrong after an update. Read them again from their stored text. Receipts you edited are left alone.
    docker compose -f deploy/docker-compose.yml exec api shop reparse
